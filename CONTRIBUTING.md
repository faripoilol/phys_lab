# Contributing

- Keep changes focused and small.
- Open an issue or describe problem/approach in your PR.
- Run basic checks before submitting:
  - `python -m py_compile track_marker_cam.py extract_frequencies_prony.py`
  - `python -m unittest discover -s tests -p 'test_*.py'`
- Do not modify `LICENSE` or `NOTICE` files unless explicitly requested.
